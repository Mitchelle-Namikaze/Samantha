# Girlfriend's Day Site

## Files expected in `assets/`

Use these exact names:

Photos:
- `photo-1.jpg`
- `photo-2.jpeg`
- `photo-3.jpeg`
- `photo-4.jpeg`

Videos:
- `vid.mp4`
- `vid1.MP4`
- `vid2.MP4`
- `vid3.mp4`

Songs:
- `song.mp4`
- `song1.mp4`
- `song2.mp4`
- `song3.mp4`
- `song4.mp4`
- `song5.mp4`

## Notes

- The envelope opens the site and starts the shuffled music.
- If a file is missing, the page will still load and show a placeholder.
- GitHub Pages is case-sensitive, so keep the filenames exactly as written.
- Open `index.html` in VS Code and edit the message text if needed.
